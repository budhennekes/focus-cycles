# FAQ and press copy

## What is Focus Cycles?
A Mac focus timer that pairs work sessions with planning and review. Choose a target, work with it beside the countdown, and note what happened afterward.

## Is it a task manager?
It is built for the work session, not for managing an entire project. Use it alongside whatever holds your tasks and documents.

## Do I have to answer every prompt?
No. Prompts are skippable. You can start with a simple one-cycle sprint or use the fuller planning and review flow.

## Can I choose my own durations?
Yes. Choose from the available focus and break durations, and set the number of cycles for your session. Do not imply arbitrary second-by-second duration entry.

## Does it work offline?
The core timer, local session records, and locally generated sounds work offline. Built-in online scenery needs a connection; your own images do not need to be fetched from Unsplash.

## Where are my notes stored?
Session plans, reviews, and history are stored on your Mac. Exported files go where you choose to save them. Online scenery contacts Unsplash, so the app is not completely network-free. See [PRIVACY_URL] for details.

## Can I export my history?
Yes, as CSV. This is a history export, not a promise of a full restorable app backup.

## Which Macs are supported?
The current release is for Apple silicon Macs. Do not advertise Intel, iPhone, iPad, Windows, web-sync, or cloud-backup support.

## Does it cost anything?
The planned first release is free, with no in-app purchases or subscription. Confirm the live listing before publishing this answer as current availability.

## Is it an official Ultraworking app?
No. Focus Cycles is an independent app inspired by Work Cycles, the framework created by Sebastian Marshall and the Ultraworking team. It is not affiliated with Ultraworking.

## Press / directory short description
Focus Cycles is a Mac focus timer that pairs planning and reflection with the countdown. Set a target, keep the next action visible, then review what happened. It includes adjustable cycles, Compact mode, local focus sounds, and session history.

## What is not needed to launch
A paid ad campaign, a long app-preview video, an automated onboarding-email series, a new logo, or a separate launch platform. Start with the Store listing, strong screenshots, and one launch announcement. This is a recommendation, not a claim that those assets could never be useful.
