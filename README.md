# Focus Cycles — browser test edition

**Try it: https://budhennekes.github.io/focus-cycles/**

No installation or account is required. Choose a Sprint for one focus session, or choose a longer session with multiple blocks. Plan, focus, and review your work.

## Testing notes

- Keep the tab open. Browser suspension or computer sleep can delay sounds; closing the tab stops alerts.
- History and personal photos stay in this browser on this device. They do not sync with the Mac app or other devices. Clearing site data removes them. Export CSV to keep a copy of session records.
- Use one active tab. Supported browsers block a second active tab to protect saved state.
- Mac-only Compact and Always on top controls are not available.
- Tested in isolated desktop Chrome at desktop and phone-size viewports. Safari, Firefox, and physical phones have not yet been verified.

Report issues at https://github.com/budhennekes/focus-cycles/issues with your browser, device, steps, expected result, and actual result. Do not include private task notes in public reports.

This branch contains the browser edition's static HTML, bundled media, and source credits. It is deployed with GitHub Pages. No analytics, login service, or cloud history sync is included.
